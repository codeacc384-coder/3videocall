Customer\n- Second participant = Advisor\n- Third participant = Officer\n- Roles now correctly displayed in video tiles and participants panel\n\n**Files Modified:**\n- `src/components/consultation/VideoConsultationRoom.tsx`\n\n---\n\n### Issue 2: Chat File Attachment Feature\n**Problem:**\n- Chat only supported text messages\n- No way to share images or documents\n-
