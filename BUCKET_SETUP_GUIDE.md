# 🪣 Supabase Storage Bucket Setup Guide\n\n## Overview\n\nYou need to create a **public storage bucket** called `consultation-attachments` where users can upload images and documents during video calls.\n\n---\n\n## Step-by-Step Setup\n\n### Step 1: Open Supabase Dashboard\n\n1. Go to [https://supabase.com](https://supabase.com)\n2. Sign in with your account\n3. Select your project: `insuranceone`\n4. You should see the dashboard\n\n---\n\n### Step 2: Navigate to Storage\n\n1. In the left sidebar, click **Storage**\n2. You'll see existing buckets (if any)\n3. Click the **New bucket** button (top right)\n\n---\n\n### Step 3: Create New Bucket\n\nA dialog will appear. Fill in:\n\n| Field | Value | Notes |\n|-------|-------|-------|\n| **Bucket name** | `consultation-attachments` | Must be lowercase, no spaces |\n| **Public bucket** | ✅ Toggle ON | Very important! Must be public |\n\n**Screenshot description:**\n```\n┌─────────────────────────────────────────┐\n│ Create a new bucket                     │\n├─────────────────────────────────────────┤\n│                                         │\n│ Bucket name:                            │\n│ [consultation-attachments]              │\n│                                         │\n│ Public bucket:                          │\n│ [✅ ON]  [❌ OFF]                       │\n│                                         │\n│ [Cancel]  [Create bucket]               │\n└─────────────────────────────────────────┘\n```\n\n4. Click **Create bucket**\n5. Wait for confirmation\n\n---\n\n### Step 4: Verify Bucket Created\n\nYou should see:\n- Bucket name: `consultation-attachments`\n- Status: Public (green indicator)\n- Empty folder structure\n\n**Screenshot description:**\n```\nStorage\n├── consultation-attachments  [🟢 Public]\n│   └── (empty)\n└── other-buckets (if any)\n```\n\n---\n\n### Step 5: Set RLS Policies\n\n1. Click on **consultation-attachments** bucket\n2. Click the **Policies** tab\n3. You'll see \"No policies yet\"\n\n---\n\n### Step 6: Add Policy 1 - Upload (INSERT)\n\n1. Click **New Policy**\n2. Select **For INSERT**\n3. Select **With custom expression**\n4. In the expression field, paste:\n\n```sql\nbucket_id = 'consultation-attachments' AND auth.role() = 'authenticated'\n```\n\n**Screenshot description:**\n```\n┌──────────────────────────────────────────────┐\n│ Create a new policy                          │\n├──────────────────────────────────────────────┤\n│                                              │\n│ Policy name: [Allow authenticated users...] │\n│                                              │\n│ Target roles: [authenticated]                │\n│                                              │\n│ Expression:                                  │\n│ [bucket_id = 'consultation-attachments'     │\n│  AND auth.role() = 'authenticated']         │\n│                                              │\n│ [Review]  [Cancel]                          │\n└──────────────────────────────────────────────┘\n```\n\n5. Click **Review**\n6. Click **Save policy**\n\n---\n\n### Step 7: Add Policy 2 - Read (SELECT)\n\n1. Click **New Policy**\n2. Select **For SELECT**\n3. Select **With custom expression**\n4. Paste:\n\n```sql\nbucket_id = 'consultation-attachments'\n```\n\n5. Click **Review**\n6. Click **Save policy**\n\n---\n\n### Step 8: Add Policy 3 - Delete (DELETE)\n\n1. Click **New Policy**\n2. Select **For DELETE**\n3. Select **With custom expression**\n4. Paste:\n\n```sql\nbucket_id = 'consultation-attachments' AND auth.uid() = owner\n```\n\n5. Click **Review**\n6. Click **Save policy**\n\n---\n\n### Step 9: Verify All Policies\n\nYou should see 3 policies:\n\n| Policy | Type | Expression |\n|--------|------|------------|\n| Allow authenticated users to upload | INSERT | `bucket_id = 'consultation-attachments' AND auth.role() = 'authenticated'` |\n| Allow public read access | SELECT | `bucket_id = 'consultation-attachments'` |\n| Allow users to delete own files | DELETE | `bucket_id = 'consultation-attachments' AND auth.uid() = owner` |\n\n**Screenshot description:**\n```\nPolicies\n├── ✅ Allow authenticated users to upload (INSERT)\n├── ✅ Allow public read access (SELECT)\n└── ✅ Allow users to delete own files (DELETE)\n```\n\n---\n\n## Bucket Configuration Summary\n\n### Bucket Details\n```\nName: consultation-attachments\nAccess: Public\nRegion: (same as your project)\nStatus: Active\n```\n\n### File Organization\n```\nconsultation-attachments/\n├── room-123/\n│   ├── 1704067200000_document.pdf\n│   ├── 1704067201000_image.png\n│   └── 1704067202000_contract.docx\n├── room-456/\n│   ├── 1704067300000_proposal.pdf\n│   └── 1704067301000_screenshot.jpg\n└── room-789/\n    └── 1704067400000_report.pdf\n```\n\n### Public URL Format\n```\nhttps://ygvcyoexgljhtgqkglkc.supabase.co/storage/v1/object/public/consultation-attachments/{room_id}/{timestamp}_{filename}\n```\n\n---\n\n## Testing the Bucket\n\n### Test 1: Upload a File\n\n1. Is bucket set to **Public**?\n3. Did you click **Create bucket**?\n\n**Fix:**\n- Delete the bucket and create again\n- Make sure to toggle \"Public bucket\" ON\n\n---\n\n### Issue: \"Permission denied\" when uploading\n\n**Check:**\n1. Are all 3 RLS policies set?\n2. Is the INSERT policy correct?\n3. Is user authenticated?\n\n**Fix:**\n- Verify INSERT policy: `bucket_id = 'consultation-attachments' AND auth.role() = 'authenticated'`\n- Make sure user is logged in\n\n---\n\n### Issue: File not visible to other participants\n\n**Check:**\n1. Is SELECT policy set?\n2. Is bucket public?\n3. Is file URL correct?\n\n**Fix:**\n- Verify SELECT policy: `bucket_id = 'consultation-attachments'`\n- Make sure bucket is public (green indicator)\n\n---\n\n### Issue: Can't delete files\n\n**Check:**\n1. Is DELETE policy set?\n2. Is user the file owner?\n\n**Fix:**\n- Verify DELETE policy: `bucket_id = 'consultation-attachments' AND auth.uid() = owner`\n\n---\n\n## Security Notes\n\n### What These Policies Do\n\n**INSERT Policy:**\n- Only authenticated users can upload\n- Prevents anonymous uploads\n- Prevents unauthorized access\n\n**SELECT Policy:**\n- Anyone can read files\n- Makes files publicly accessible\n- Allows sharing with external users\n\n**DELETE Policy:**\n- Users can only delete their own files\n- Prevents users from deleting others' files\n- Maintains data integrity\n\n---\n\n## File Size Limits\n\n- **Max file size:** 50 MB (default)\n- **Supported types:** Any file type\n- **Recommended:** Images (jpg, png, gif) and Documents (pdf, doc, docx)\n\n---\n\n## Storage Costs\n\n- **Free tier:** 1 GB storage\n- **Paid tier:** $0.05 per GB\n- **Bandwidth:** Included in plan\n\n---\n\n## Verification Checklist\n\n- [ ] Bucket created: `consultation-attachments`\n- [ ] Bucket is public\n- [ ] INSERT policy set\n- [ ] SELECT policy set\n- [ ] DELETE policy set\n- [ ] Can upload files\n- [ ] Files visible in storage\n- [ ] Files downloadable\n- [ ] Other participants see files\n\n---\n\n## Next Steps\n\n1. ✅ Create bucket (this guide)\n2. ✅ Set RLS policies (this guide)\n3.
